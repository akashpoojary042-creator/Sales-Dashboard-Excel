# 📊 Sales Dashboard using Microsoft Excel

## Project Overview

This project is an interactive Sales Dashboard created using Microsoft Excel.
The dashboard helps analyze sales performance using KPIs, Pivot Tables, Pivot Charts, and Slicers.

---

## Key Performance Indicators

- Total Revenue
- Total Orders
- Total Quantity Sold
- Average Order Value

---

## Dashboard Features

- Interactive Slicers
- Timeline Filters
- Monthly Revenue Trend
- Revenue by Category
- Revenue by Occasion
- Top 10 Cities by Revenue
- Top 5 Products by Revenue
- Revenue by Gender

---
